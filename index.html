فصل ۱ · مبانی ریاضی صفحه ۱۲

🔹 مفهوم مجموعه: مجموعه به دسته‌ای از اشیاء مشخص گفته می‌شود. اعضای مجموعه می‌توانند اعداد، اشیاء یا حتی مفاهیم باشند. در ریاضیات، مجموعه‌ها پایه‌گذار بسیاری از نظریه‌ها هستند.

🔹 نمادگذاری: برای نمایش مجموعه از حروف بزرگ مانند A, B, C استفاده می‌کنیم. اعضا را درون { } قرار می‌دهیم. مثال: A = {1, 2, 3}

🔹 اجتماع و اشتراک: اجتماع دو مجموعه شامل تمام اعضایی است که در حداقل یکی از مجموعه‌ها وجود دارند. اشتراک نیز شامل اعضای مشترک هر دو مجموعه است.

نکته مهم: مجموعه تهی (∅) هیچ عضوی ندارد و زیرمجموعه هر مجموعه‌ای است.
